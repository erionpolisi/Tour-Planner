# Tour Planner App

## Overview
A simple tour planning application to manage and organize tours efficiently.

## Tech Stack
- Frontend: Angular
- Backend: C# (.NET)
- Project Management: Jira
- Design: Figma

## Features
- Create and manage tours
- Store and display tour information
- Simple and clean UI

## Tools
- Jira for task tracking
- Figma for UI/UX design
- GitHub for version control

### Frontend
